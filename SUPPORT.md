# Getting help

- **A question, or an idea:** start a thread in [Discussions](https://github.com/DrummingBird1/clipforge-app/discussions). Ideas and votes there help decide what goes on the [roadmap](ROADMAP.md).
- **Something doesn't work:** read the [troubleshooting section](README.md#troubleshooting) of the README first. It covers the Windows SmartScreen warning, antivirus false positives, a busy port, where your data lives, updating and uninstalling. If your problem isn't there, [open an issue](https://github.com/DrummingBird1/clipforge-app/issues/new/choose) with the bug report form. It asks what happened, the steps to reproduce it, your ClipForge version, how you run it, your Windows version and GPU, and any error messages, which is what makes a bug fixable.
- **A security problem:** don't open a public issue. Use the [private form](https://github.com/DrummingBird1/clipforge-app/security/advisories/new), as described in [SECURITY.md](SECURITY.md).
- **Want to help:** see [CONTRIBUTING.md](CONTRIBUTING.md). Issues labeled [good first issue](https://github.com/DrummingBird1/clipforge-app/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) are a good place to start, and a translation of the interface is always welcome.

Please keep your videos, keys (`.env`, `client_secret.json`) and personal paths out of anything you post. Screenshots of the ClipForge window are fine, and the diagnostics screen (🩺) shows which keys are set without showing them.
