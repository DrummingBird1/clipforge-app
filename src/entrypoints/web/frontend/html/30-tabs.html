📅 ריקאפ אוטומטי (שבועי/חודשי/שנתי)

יום-בשבוע רלוונטי רק ל"שבועי" - חודשי/שנתי רצים בתאריך קבוע (1 לחודש / 1 בינואר).

🔗 אחרי שקליפ נכנס (OBS / תיקיית לכידה)

מאזין "משדר-העל" (מצב obs או folder) מעתיק כל קליפ ל-Import - ומשם השרת ממשיך לבד, בתור הרינדור הרגיל.

🌊 תצוגת גל קול

עוזר לכוון את סף הרעש (--noise_threshold) של story_cutter.py לפני ריצה.

🔊 פאנל אפקטים קוליים לסטרימינג

מנגן דרך הרמקולים של המחשב שמריץ את השרת (לא דרך הדפדפן) - נכון גם כשגולשים מטלפון במצב --lan.
